# sf-ecs-odin

SF ECS Odin owns a self-contained ECS runtime and Unity authoring integration. The ECS kernel is embedded under SFramework.ECS.Runtime. Use SF Core's SFContainer and generated automatic service fields for system services. Odin remains an installed dependency; other ECS variants are separate APIs.

Read [the package README](../README.md) for dependencies and tests. Keep package-specific knowledge in this AI~ folder alongside its source; refresh consumers through sf-ai after changes.
